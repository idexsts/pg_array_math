
<h1 align="center">pg_array_math</h1>

<p align="justify">
Расширение для PostgreSQL, реализующее поэлементные
арифметические и математические операции над одномерными числовыми массивами.
</p>

<h2 align="center">1. Описание задач</h2>

<h3>1.1. Назначение расширения</h3>

<p align="justify">
Расширение <strong>pg_array_math</strong> предназначено для выполнения математических операций над одномерными массивами в системе управления базами данных PostgreSQL. Оно предоставляет набор пользовательских функций, реализованных на языке C, которые позволяют выполнять арифметические вычисления и математические преобразования непосредственно средствами SQL.
</p>

<h3>1.2. Реализованные возможности</h3>

<p align="justify">
Расширение <strong>pg_array_math</strong> предоставляет 11 пользовательских функций для выполнения математических операций над массивами PostgreSQL. Реализованные функции можно разделить на три основные группы:
</p>
<strong>1. Арифметические операции над двумя массивами (бинарные операции):</strong>

- `array_add` — поэлементное сложение двух массивов;
- `array_sub` — поэлементное вычитание элементов второго массива из соответствующих элементов первого;
- `array_mul` — поэлементное умножение двух массивов;
- `array_div` — поэлементное деление элементов первого массива на соответствующие элементы второго.

<strong>2. Арифметические операции над массивом и числом:</strong>

- `array_add_scalar` — прибавление заданного числа к каждому элементу массива;
- `array_mul_scalar` — умножение каждого элемента массива на заданное число.

<strong>3. Математические функции:</strong>

- `array_power` — возведение каждого элемента массива в заданную степень;
- `array_sqrt` — вычисление квадратного корня каждого элемента массива;
- `array_abs` — вычисление абсолютного значения каждого элемента массива;
- `array_log` — вычисление натурального логарифма каждого элемента массива;
- `array_exp` — вычисление экспоненты каждого элемента массива.

<p align="justify">
Для выполнения вычислений поддерживаются числовые типы данных SMALLINT, INTEGER, BIGINT, REAL, DOUBLE PRECISION и NUMERIC. При этом набор поддерживаемых типов зависит от конкретной функции и характера выполняемой операции. Об этом подробнее в разделе ...
</p>

<p align="justify">
Дополнительно реализована обработка некорректных входных данных и граничных случаев, включая проверку совместимости массивов, деление на ноль, недопустимые значения для математических операций и переполнение числовых типов.
</p>
